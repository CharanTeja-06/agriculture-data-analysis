# Seasonal Agriculture Performance Analysis

A data analytics project studying how farming performance changes across seasons (Kharif, Rabi, Zaid) using a dataset of 4,000 farm records from 8 Indian states.

## About

This project explores how yield, cost, revenue, profit, resource usage, and disease/pest risk vary by season. It includes full data cleaning, exploratory data analysis, correlation analysis, and statistical significance testing to confirm whether the seasonal differences observed are real or just noise.

## Dataset

- 4,000 farm records
- 28 columns covering environmental conditions, resource usage, and economic outcomes
- Seasons: Kharif, Rabi, Zaid
- Crops: Wheat, Rice, Maize, Pulses, Cotton, Chilli, Groundnut, Sugarcane
- States: 8 Indian states

## What's Included

- Missing value handling (season/crop-aware imputation)
- Outlier detection and treatment
- Season-wise comparison of yield, cost, profit, and resource usage
- Crop x Season and Irrigation x Season performance heatmaps
- Correlation analysis between environmental factors and yield/profit
- ANOVA testing to confirm statistical significance of seasonal differences
- Answers to all key project questions, backed by the analysis

## Tech Stack
